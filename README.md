# Kalkulator Operasi Matriks — Streamlit

## Menjalankan di komputer
1. Install Python.
2. Buka CMD/Terminal di folder ini.
3. Jalankan:
   `pip install -r requirements.txt`
4. Jalankan:
   `streamlit run app.py`

## Deployment ke Streamlit Community Cloud
1. Upload `app.py` dan `requirements.txt` ke repository GitHub.
2. Buka Streamlit Community Cloud.
3. Pilih repository dan file `app.py`.
4. Deploy.

Aplikasi mempertahankan fungsi dari program asli:
- Matriks A 2×3
- Matriks B 3×2
- Perkalian A × B
- Detail setiap elemen AB
- Determinan AB
- Rank AB
- Invers AB jika determinan tidak nol
